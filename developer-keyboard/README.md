# Tastiera italiana per sviluppatori

## Windows

Link al download di un layout di tastiera che include alcuni tasti specifici per sviluppatori:

https://github.com/linuxiamo/devs-kb-layout-ita

Tra i tasti aggiuntivi vengono installati:

- tilde (`~`) : <kbd>AltGr</kbd> + <kbd>ì</kbd>
- backtick (`` ` ``) : <kbd>AltGr</kbd> + <kbd>'</kbd>

Per cambiare metodo di input (passare da una tastiera all'altra) premere tasto WINDOWS + BARRA SPAZIATRICE

Altri simboli utili sono già disponibili:

- `[` : <kbd>AltGr</kbd> + <kbd>è</kbd>
- `]` : <kbd>AltGr</kbd> + <kbd>+</kbd>
- `{` : <kbd>AltGr</kbd> + <kbd>Shift</kbd> + <kbd>è</kbd>
- `}` : <kbd>AltGr</kbd> + <kbd>Shift</kbd> + <kbd>+</kbd>

## MacOS

In caso si utilizzi macOS con una tastiera italiana, alcune utili combinazioni di tasti sono:

- `[` : <kbd>Option</kbd> + <kbd>è</kbd>
- `]` : <kbd>Option</kbd> + <kbd>+</kbd>
- `{` : <kbd>Option</kbd> + <kbd>Shift</kbd> + <kbd>è</kbd>
- `}` : <kbd>Option</kbd> + <kbd>Shift</kbd> + <kbd>+</kbd>
- tilde (`~`): <kbd>Option</kbd> + <kbd>5</kbd>
- backtick (`` ` ``): <kbd>Option</kbd> + <kbd>9</kbd>

Qualora necessario, per cercare ulteriori combinazioni è possibile avvalersi del visualizzatore di tastiera di macOS come descritto in [questa guida](https://support.apple.com/it-it/guide/mac-help/mchlp1015/mac).
